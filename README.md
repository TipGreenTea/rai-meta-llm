# rai-meta-llm (Data and Code will be available upon paper acceptance)
Meta-analysis of 495 Ethical AI review papers and automated classification using LLM models under zero-shot and few-shot settings. Includes dataset, prompts, and evaluation code.


---

## 📊 Dataset

- 495 review papers manually annotated by domain and ethical category.
- Covers 7 application domains (e.g., Healthcare, Education, Finance).
- Labels: `Transparency`, `Fairness`, `Privacy`, `General Ethics`.
- Data provided in CSV format with fields: `title`, `abstract`, `domain`, `label`.
